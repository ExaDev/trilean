# trilean-json-shape-derive

`#[derive(Shape)]` for [`trilean-json-shape`](https://crates.io/crates/trilean-json-shape). Use it through that crate, which re-exports it. The derive reads the serde attributes a type already carries and refuses at compile time what could never validate.

Part of [trilean](https://github.com/ExaDev/trilean).
